This site is plain HTML and CSS, generated by Jekyll and served by GitHub Pages. The JavaScript is small: one file applies your saved light or dark choice before the page paints, and another runs the theme switch, the Kolkata clock and the copy button. Cloudflare adds two small scripts of its own: the cookieless Web Analytics beacon and the decoder for its email-address obfuscation.

Two typefaces do all the work: Instrument Sans for reading, and Fragment Mono for times, dates and labels. Both are open source under the SIL Open Font License, subset to Latin and served from this domain. A strict Content-Security-Policy allows scripts only from this site and from Cloudflare Web Analytics.

It tests itself. On every pull request and every push to master, Playwright loads each page at three screen sizes and fails on console errors, CSP violations or horizontal overflow; axe checks accessibility, including colour contrast, in light and dark; Lighthouse fails the build if the accessibility score drops below 100; the HTML is validated and the links are checked.

The previous version was a hand-drawn sketchbook. This one aims for what I want from the systems I build: precise, quiet, and easy to maintain.
